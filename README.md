# 瑪奇 Mobile 木材＋助手

瑪奇 Mobile 木材＋助手 — 空白鍵版（Windows 前景）

需要 Windows 與 Python 3（含 tkinter、Python Launcher）。
首次使用：先執行 install.bat，再執行 start.bat。
舊版更新：關閉助手，只覆蓋 woodplus.py；保留 settings.json、wood.png、disabled.png。
舊版更新必須重做第 3 項「不能加工按鈕」校正；其餘三項可沿用。加工與領取座標不再使用。

操作流程：滑鼠點木材／木材＋卡片 → 比對是否為不能加工的固定暗藍樣式 → 按一次空白鍵加工
→ 等待 → 在加工主畫面按空白鍵全部領取 → 等待結果動畫 → 再按空白鍵確認。
每次排入加工後，會重新點卡片。一次只排一批。
木材＋優先，不能加工時補一批木材；補完仍不能做木材＋就停止。
原料不足可能留下不足一批的餘料，樹液不足也會停止。

首次校正四項：
1. 主畫面第一格木材圖示中央（同時記錄主畫面樣本）。
2. 主畫面第二格木材＋卡片。
3. 開啟任一材料不足的配方，取固定暗藍色加工按鈕左側內部，距邊至少 20 像素，避開文字與圓角。
4. 能關閉配方視窗的空白處（請先手動確認點擊有效）。
每項校正按確定後，5 秒內切回遊戲並將滑鼠放在指定位置。
視窗位置、大小與顯示縮放不得改變。

開始前手動領取成品、清空所有加工欄位，停在木材加工主畫面。
切回遊戲按 F8，2 秒後執行；F10 停止。
也可點助手的開始按鈕，5 秒內切回遊戲。
執行期間遊戲須保持前景，失去焦點即停止；滑鼠移到主螢幕左上角也能緊急停止。
停止後可能仍有一批加工中，重開前須手動領取並清空佇列。

木材預設等 60 秒，木材＋390 秒；可調整但須大於實際加工時間。
新版採反向判斷：符合不能加工的暗藍樣本就略過；不符合則嘗試按一次空白鍵。
必須確認配方視窗關閉才繼續等待，未關閉立即停止，不會連續送鍵。
仍使用固定位置的 20×20 取樣；本版不搜尋整顆按鈕。視窗大小與位置須保持固定。
若卡片打開後沒按空白鍵，請查看 run.log 並確認第 3 項取樣正確。
此版未實機驗證，請監看一輪。畫面辨識不能確認所有彈窗或實際成品數量。

領取確認版：領取後等待 1.2 秒（另有按鍵後緩衝），再按一次空白鍵關閉「加工完成」視窗。
確認後最多等約 3 秒回到加工主畫面，若仍未返回便停止，不重複送鍵。
更新只需覆蓋 woodplus.py；現有四項校正可沿用。
