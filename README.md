# 瑪奇 Mobile 前景加工助手 v2

Windows 電腦版。可在介面手動新增加工品，以加工台編號與材料卡片編號定位。

## 安裝與執行

安裝 Python 3（含 tkinter 與 Python Launcher），執行 `install.bat`，再執行 `start.bat`。
也可執行 `py -3 -m pip install -r requirements.txt` 安裝相依套件。

開始前先關閉遊戲全部頁面、手動領取成品並清空加工佇列，篩選設「全部」、材料清單置頂。
在助手選配方、輸入目標批次（0＝做到缺料），切回遊戲按 **F8**。**F10** 停止。
執行中須保持遊戲前景，不能移動視窗或改變大小。滑鼠移到主螢幕左上角也能緊急停止。

## 進入設備與加工流程

1. 按 K 開啟生活製作選單。
2. W 三下定位到第一頁，再 S 一下定位到加工頁。此流程以分頁在頂端不循環為前提。
3. 點選加工台，再點左側「前往設備」。
4. 必須先觀察到預覽頁離開，再等待同一加工頁標題重新出現。逾時停止。
5. 依卡片編號點材料。符合「不能加工」暗藍色時跳過；否則空白鍵加工。
6. 等待設定秒數，空白鍵領取，等待結果動畫，再按空白鍵確認。
7. 確認回到加工頁後，才繼續下一批。

加工台：1 金屬、2 木材、3 皮革、4 布料、5 藥品、6 食材。
材料由左到右、由上到下編號，依「共用版面」的每列張數計算。
預設對應提供的 1920×1080 圖片，按遊戲內容區大小等比例換算，建議 16:9。
若遊戲縮放造成排列改變，請調整共用版面；不保證任何解析度都無須設定。

## 手動新增與修改材料

在「配方管理」輸入唯一 ID、名稱、加工台編號、材料編號、等待秒數、每批產量。
按「新增／更新」儲存，相同 ID 會更新該配方。修改 ID 視為新增。
等待秒數請填入實際加工時間加緩衝；每批產量為參考資訊，本版依完成批次計數，不辨識大成功。

可選填「前置 ID」。例如木材＋缺料時補一批木材，再試一次木材＋。
目前前置材料須在同一加工台，僅適合缺一批即可補足的鏈。補完後仍不能加工就停止，避免其他原料不足時無限補料。
本版每次執行一個加工台，可選任意台的已登錄材料；尚未自動跨台補料或辨識每種原料數量。

預設保留木材與木材＋兩個配方，其他材料由使用者新增。
不需要逐材料截圖或座標校正，設備標題比對樣本是在本次導航時暫存於記憶體。
不能加工判斷仍有共用取樣位置與 RGB，可在版面設定修改。
不自動捲動；只支援目前畫面可見的卡片。

## 更新與設定

下載新版本後覆蓋程式檔（包含新增的 `craft_core.py`），再執行 `start.bat`。
新版使用 `craft_config.json`，舊版 `settings.json` 與校正圖片保留但不再讀取。
所有配方與共用版面會保存在 `craft_config.json`，操作記錄在 `run.log`。
設定檔與記錄不納入 Git。

尚未在實際 Windows 遊戲環境驗證。先使用目標 1 批監看，確認導航、移動抵達、加工及領取確認皆正確。
頁面判斷使用標題畫面差異，非語意或文字辨識；圖形相近的異常頁面仍可能誤判。
若抵達速度太快而沒觀察到頁面離開，程式會停止，請提供操作畫面供調整。

## 驗證

`py -3 -m unittest discover -s tests -v` 可執行配方與模擬流程測試，不會操作遊戲。
